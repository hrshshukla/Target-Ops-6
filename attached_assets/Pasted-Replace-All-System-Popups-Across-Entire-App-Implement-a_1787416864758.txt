Replace All System Popups Across Entire App

Implement a global custom popup/modal system across the entire React Native + Expo app.

The goal is to completely replace all native/system popup dialogs with a consistent custom in-app popup.

Requirements
Search the entire codebase for every use of:
Alert.alert()
Native/system confirmation dialogs
Any other Android/iOS system popup being used for user-facing messages
Replace every such popup across the entire app, not just the Sign In/Login or Account Creation screens.
This includes all screens, authentication flows, employee/guard/company flows, settings, forms, API error messages, success messages, confirmations, logout confirmation, delete confirmation, validation messages, etc.
Do not leave any user-facing Alert.alert() or system popup behind unless it is technically required by the operating system.
Reusable Custom Modal

Create a centralized reusable component, for example:

components/ui/CustomModal.tsx

and preferably a centralized modal manager/context/hook so any screen can trigger it without duplicating modal code.

It should support:

Success
Error
Warning
Information
Confirmation
Custom messages
One or two action buttons
Custom button labels
Dismiss/cancel action
Loading state where required

Example usage should be simple, such as:

showModal({ type: "success", title: "...", message: "...", ... })

UI/UX

The popup must be completely custom-rendered inside the app, not an Android/iOS system dialog.

Match the existing app's design system and theme.
Dark themed appearance consistent with the application.
Rounded corners.
Proper padding and spacing.
Clear title and message hierarchy.
Custom buttons matching the existing app.
Semi-transparent backdrop.
Smooth fade/scale animation.
Responsive on different Android screen sizes.
Proper safe-area handling.
Prevent interaction with the screen behind the modal while it is open.
Handle keyboard visibility correctly where applicable.
Important

Do not change existing business logic.

Do not change:

API behavior
Authentication logic
Navigation flow
Form validation logic
Database operations
Existing functionality

Only replace the way user-facing popup messages/dialogs are displayed.

For example, the existing:

Alert.alert("Account created", "...", [{ text: "SIGN IN", ... }])

should continue performing exactly the same action, but the UI must now be the custom modal.

Final Verification

After implementation:

Search the entire project for Alert.alert.
Search for other native/system dialog implementations.
Replace all user-facing occurrences with the centralized custom modal.
Make sure different screens can trigger the modal independently.
Make sure there are no duplicate modal implementations unnecessarily.
Make sure the app builds and runs without errors.

This must be implemented globally across the entire app, not only on the login/sign-in/account-creation screens.
